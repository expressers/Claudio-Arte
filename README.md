# Cláudio Arte

Site do artista Cláudio Arte. Vite + React, publicado no Render (deploy automático a partir da branch main).

```bash
npm install
npm run dev
```

- Obras e fotografias: `public/img` e a lista em `src/data.js`
- Contactos: constantes `WHATSAPP` e `INSTAGRAM` em `src/App.jsx`
- Direcção visual: `DESIGN.md`; contexto do produto: `PRODUCT.md`
